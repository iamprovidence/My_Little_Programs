gRPC Guide

gRPC can't be called from a browser page. gRPC runs on HTTP/2 and relies on parts of it (binary frames, trailers) that browser JavaScript can't control. On top of that this server speaks HTTP/2 without TLS (h2c), which browsers don't support at all. So there is no "try it" page like Scalar or Banana Cake Pop: use one of the clients below instead.

How to call it

GUI

Postman

Nothing to set up on the server: Postman reads the services through reflection.

  1. New → gRPC.
  2. Enter the URL {{ADDRESS}}. Keep TLS off (the lock icon).
  3. In Service definition pick Using server reflection.
  4. Select a method, for example PlatformGrpc / AddPlatform, fill the message and press Invoke.
CLI

grpcurl

Install it once:

winget install fullstorydev.grpcurl

List services and call methods:

grpcurl -plaintext {{ADDRESS}} list PlatformGrpc
grpcurl -plaintext {{ADDRESS}} PlatformGrpc/GetPlatforms
grpcurl -plaintext -d '{"Name": "Docker"}' {{ADDRESS}} PlatformGrpc/AddPlatform

Subscribe to the stream: it waits until a platform is added from another client and prints it.

grpcurl -plaintext {{ADDRESS}} PlatformGrpc/SubscribeToAddPlatform
Web UI

grpcui

The closest thing to Swagger for gRPC: it starts a local web page and makes the gRPC calls for the browser. Download it from GitHub releases (or go install github.com/fullstorydev/grpcui/cmd/grpcui@latest), then: 

grpcui -plaintext {{ADDRESS}}
